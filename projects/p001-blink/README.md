# Project 1: Blink

Book chapter: 1

## What it does

Blinks the built-in L LED. It stays on for one second, then off for one
second.

## Parts

- Arduino Uno R3
- USB cable

No external parts.

## Wiring

None. Uses the built-in LED on pin 13.

## Upload
1. Open the .ino file in Arduino IDE 2.
2. Select Arduino Uno and its port.
3. Click Upload.

## What you should see

The L LED flashes once every two seconds.

## Change it

Change both delays to 250. Upload and watch. Then try 10. Why does the
LED look dim instead of blinking?
