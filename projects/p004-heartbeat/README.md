# Project 4: Heartbeat

Book chapter: 1

## What it does

Makes a double pulse once per second, like a heartbeat. REST is worked
out from BEAT, so one whole beat always takes the same time.

## Parts

- Arduino Uno R3
- USB cable

No external parts.

## Wiring

None. Uses the built-in LED on pin 13.

## Upload
1. Open the .ino file in Arduino IDE 2.
2. Select Arduino Uno and its port.
3. Click Upload.

## What you should see

Two quick flashes, then a rest. That is one beat. You get exactly 60
beats per minute.

## Change it

Set BEAT for 150 beats per minute. How many ms is one beat?
