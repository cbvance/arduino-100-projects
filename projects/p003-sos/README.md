# Project 3: SOS

Book chapter: 1

## What it does

Flashes SOS in Morse code. It uses two functions, dot() and dash(), and
for loops. All the timing comes from one number: DOT.

## Parts

- Arduino Uno R3
- USB cable

No external parts.

## Wiring

None. Uses the built-in LED on pin 13.

## Upload
1. Open the .ino file in Arduino IDE 2.
2. Select Arduino Uno and its port.
3. Click Upload.

## What you should see

Three short flashes, three long flashes, three short flashes. Then a
1.4 s pause. Then it repeats.

## Change it

Send OK instead of SOS. O is dash, dash, dash. K is dash, dot, dash.
